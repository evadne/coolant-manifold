# Licensing and third party provenance

The operator has elected to decide the project's reuse licence after the publication review. No licence has been selected for the original CAD, scripts, documentation or photographs. This file is a status/provenance notice, not a licence grant. Do not label the repository MIT, Creative Commons or CERN-OHL until that decision is made.

The repository intentionally retains retrieved reference files, supplier records and history. Keeping a file here does not identify it as original project work or apply a future project licence to it.
